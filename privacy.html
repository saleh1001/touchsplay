Privacy Policy for BlockBot

Last updated: June 11, 2026

We take the privacy and security of our users very seriously. This page clearly drafts how the bot handles, protects, and utilizes data to deliver our advanced automation, block systems, and real-time protection shields.

1. The Data We Collect & Store

To operate our fully automated moderation and shield systems, the bot ONLY stores minimum descriptive metadata in our secure MongoDB database:

  • ✓ Discord User IDs: Required to uniquely identify members and manage their active ban/block states.
  • ✓ Discord Role IDs: Used to accurately preserve and restore their original roles once punishment ends.
  • ✓ Log IDs & Punishment Logs: Kept to document active and historic action audits for server administrators.

⚠️ 2. Crucial Note on Message Content

The bot temporarily processes deleted message content strictly and in real-time to relay it to the secure internal backup logging channels within your Discord server.

CRUCIAL NOTE: Absolutely NO message content is ever saved, extracted, or stored in our MongoDB or any external databases. Native text processing is transient, staying only in warm memory, and is discarded immediately after transmitting to your server.

3. How We Use the Data

Stored descriptive metadata is strictly restricted to facilitating the server safety automation workflows:

  • • Temporary Punishment Lifecycles: Tracking block durations and expiration intervals so the bot can automatically restore original server permissions.
  • • Anti-Abuse Shield System: Monitoring server-side role changes in real-time to detect, rollback, and prevent unauthorized manual adjustments.

4. Data Storage & Security

All logged metadata resides safely within isolated environments:

  • ✓ We DO NOT use collected metadata to train artificial intelligence (AI) models.
  • ✓ We never sell, trade, rent, or share server metadata with third parties.

5. User Rights & Data Removal

Users and server administrators can request continuous, permanent deletion of their metadata and logs at any point free of charge by contacting the developer via Discord.
